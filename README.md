## Cometary impacts an unlikely pathway towards the origins of life on Earth

This repository contains the code used to generate the figures in Anslow, McDonald, Bonsor, Rimmer, Rae (2026; in press Scientific Reports).

- ALl scripts used to produce the figures in the main and supplementary text can be found in the sub-directory paper_figures/ [format this text somehow?].
- Analysis scripts, used to perform the Monte Carlo impact experiments of cometary delivery, are contained in the sub-directory analysis/
